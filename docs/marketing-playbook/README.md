# Маркетинг, продвижение и продажи: рабочая база

Проверено 14 октября 2026 года. Первая прикладная версия для GrantPlan; методику можно переносить в другие проекты после проверки их аудитории, продукта и экономики.

Цель: получать подходящие обращения и оплаченные заказы, понимать источник результата и постепенно снижать стоимость привлечения. Просмотры, поисковые показы и клики полезны для диагностики, но не заменяют продажи.

## Как читать выводы

**Факт** — ограниченное утверждение, поддержанное указанным первоисточником. **Рабочая гипотеза** — наша идея, которую ещё предстоит проверить. **Учебный пример** — придуманные числа для проверки расчёта. Ни одна из этих меток не означает гарантию роста.

Это собственные конспекты и рабочие материалы со ссылками, а не архив чужих статей. Клиентские документы, контакты, ключи API и приватные отчёты кабинетов сюда не включены. Сохранение базы помогает повторно использовать проверенные знания; веса моделей от этого не меняются.

Основной текущий путь GrantPlan: Google Поиск → полезный материал или услуга → аудит идеи → предложение по составу работы → заказ. Дополнительный путь: Shorts → профиль канала → сайт. Платный трафик рассматривается как будущий эксперимент с отдельным бюджетом.

## Поддержание актуальности

Перед изменением рекламной кампании перепроверить правила платформы. Раз в месяц пересматривать источники, раз в неделю — журнал экспериментов. Новую версию вывода сохранять с датой и причиной изменения. Условия грантов проверять отдельно по официальным документам перед публикацией; эта база не заменяет их.
