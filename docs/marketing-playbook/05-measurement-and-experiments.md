# Измерение: от показа до заказа

Дата: 14.10.2026. Это схема учёта и проверки; она не означает, что все её события уже установлены в рабочем кабинете.

## Разные источники отвечают на разные вопросы

| Источник | Что измеряет | Чего из него нельзя заключить |
| --- | --- | --- |
| Search Console | Показы, клики, запросы и страницы в поиске | Каждый клик — отдельный клиент |
| GA4 | Наблюдаемые посещения и события сайта | Все люди измерены независимо от согласия и блокировок |
| YouTube Studio | Просмотр и реакцию на ролики | Каждый просмотр привёл человека на сайт |
| Приватный учёт заявок и оплат | Реальные обращения и сделки | Весь эффект рекламы доказан без сопоставления источников |

Не требовать равенства кликов Search Console и сессий GA4. Окна, метрики и доступность данных различаются. Технические проверки помечать отдельно и не называть клиентами.

## События и стадия готовности

| Сигнал | Правильное значение | Текущая проверка кода |
| --- | --- | --- |
| `start_audit` | Интерес к началу аудита | Есть в ссылках интерфейса |
| `download_audit_worksheet` | Загрузка подготовительной анкеты | Есть в статье |
| `submit_form` → `generate_lead` | Подтверждённая доставка обращения | Сопоставление есть в `src/lib/analytics.ts` |
| `qualify_lead` | Лид признан подходящим для нашей услуги | Предлагается для будущего приватного процесса |
| `close_convert_lead` | Сделка подтверждена как оплаченная по принятому определению | Предлагается; не установлен этим пакетом |

Для `generate_lead` нельзя использовать простой клик по кнопке отправки. В GrantPlan результат доставки описан в [документации формы](../lead-delivery.md). Наличие вызова в коде не доказывает его получение GA4 при реальном посещении.

Названия стадий поддерживаются [рекомендованными событиями Google](https://support.google.com/analytics/answer/16376749?hl=en). Кастомное событие также может быть полезным; маппинг названия сам по себе не делает его ключевым событием и не запускает оптимизацию рекламы.

## UTM

Единые названия — нижний регистр, без контактов и свободного текста клиента. Внешняя ссылка содержит `utm_source`, `utm_medium`, `utm_campaign`, при необходимости `utm_content`. [Документация](https://support.google.com/analytics/answer/10917952?hl=en).

Для профиля YouTube: `youtube / organic_video / grantplan_education / channel_profile`. Один профильный линк не позволяет определить конкретный Short. Внутренние переходы по сайту UTM-метками не размечать: используем события и расположение ссылки.

URL, параметры событий и выгрузки GA4 не должны содержать телефоны, email, имя, документы или свободное описание клиента. [Политика PII](https://support.google.com/analytics/answer/6366371?hl=en).

## Эксперимент

Заранее записать гипотезу, изменение, основной показатель, срок, минимальный объём, ограничения и правило решения. Менять один важный элемент за раз. Сравнение двух роликов в разные дни — наблюдение с возможными внешними причинами; оно не равно случайному A/B-тесту.

Практический журнал: [experiments.csv](templates/experiments.csv). `proposed` означает, что эксперимент ещё не запускался. Нельзя задним числом выбрать «победивший» показатель и объявить гипотезу доказанной.

Если из 100 независимых подходящих посещений получено 0 обращений, точная односторонняя верхняя 95% граница вероятности равна `1 − 0,05^(1/100) ≈ 2,95%`. Следовательно, ноль наблюдаемых лидов не доказывает нулевую конверсию. Эта математическая модель предполагает одинаковую вероятность и независимость посещений; смесь каналов и повторные визиты могут нарушать предпосылки.

## Наши проверки

Для отделения собственного трафика сначала определить устойчивый способ его пометки и режим Testing. Активный фильтр GA4 меняет входящие данные необратимо; широкий диапазон IP может исключить настоящих людей. [S08](https://support.google.com/analytics/answer/10104470?hl=en). В этом этапе фильтры не меняются.

Еженедельный разбор: где прерывается путь, что человек ожидал, какие причины подтверждены, какое одно изменение проверим следующим. Публично хранить методику и обезличенные учебные примеры; фактический журнал контактов и оплат — в приватном учёте.
