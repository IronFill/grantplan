# Готова карусель для органічного розміщення

Створено 15.10.2026. Три оригінальні картки PNG 1080×1350, порядок: 01 → 02 → 03. Перегляд усіх карток: preview.jpg. Тексти й альтернативні описи: caption.uk.md. Журнал: placement-tracker.csv.

Призначення — корисний допис у власній сторінці GrantPlan; у чужій спільноті лише за її правилами. На дату підготовки матеріал не опублікований, статистика порожня навмисно. Немає підтвердження, що метрики або функції соцмереж доступні в поточному акаунті.

Chrome видно в переліку браузерів, але запит інструмента повернув Unable to load browser request-header policy; службовий запит отримав Cloudflare block. Це технічна проблема інструмента, а не підтвердження блокування Facebook. Повторна перевірка 15.10.2026 не відновила доступ; завантажень у Meta не виконано.

Розрахунок 32 000 / 100 = 320 перевірений. Внесок — сума після змінних витрат, що покриває постійні витрати, не чистий прибуток. Перелік витрат загальний, не правило допустимих витрат гранту. Переглянуто монтаж-прев’ю всіх трьох карток: текст у межах, без накладань. Повного рендеру в інтерфейсі соцмереж поки немає.

Відтворення: Python + Pillow, generate.py; шрифти Arial з Windows. У пакеті немає сторонніх фотографій або клієнтських даних. Шрифти не розповсюджуються.

Наступний крок після відновлення доступу: перевірити профіль GrantPlan і посилання → завантажити картки та підпис → записати фактичний URL/час → після однакового періоду порівняти переходи та підтверджені звернення. Порожня таблиця не означає нульовий трафік — він ще не виміряний для цього матеріалу.
