# Кошторис без сюрпризів

Три авторські типографічні картки 1080×1350 для одного допису-галереї. Це похідний формат уже опублікованої статті, а не новий клієнтський кейс. Числа навчальні: товари98000, доставка2000, початковий підсумок100000; сценарій +10% лише на товари дає109800.

Порядок: `01-hook.png`, `02-check.png`, `03-scenario.png`. `preview.jpg` — лише огляд, не четверте вкладення. Генератор `render.py` використовує Pillow й системний Arial; шрифти не входять до репозиторію. Приклад запуску: `python render.py --font-dir C:/Windows/Fonts`.

Опис для доступності:
1. «Навчальна картка GrantPlan: 100000грн у таблиці. А доставка — пішки? Правильний підсумок ще не означає повну перевірку».
2. «Три перевірки кошторису: комплектація і кількість, повна ціна з доставкою та монтажем, строк дії пропозиції постачальника».
3. «Навчальний сценарій: покупки98000грн дорожчають на10%, доставка2000грн незмінна, разом109800грн. Умовні цифри, не прогноз цін; допустимість витрат залежить від програми».

## Текст допису

Кавомашина в кошику. Доставка — «потім». Монтаж — «розберемося». І ось бюджет уже має власні плани 🙂

Перед тим як переносити ціну в бізнес-план, уточніть комплектацію, повну суму та строк дії пропозиції. Перевірте, що одну витрату не порахували двічі.

На картках — умовний приклад, а не ринкові ціни чи готова грантова заявка. Допустимість покупок перевіряйте за умовами своєї програми.
