# Податковий кодекс України — навігація по повному тексту

**Джерело:** файл наданий клієнтом напряму (docx → PDF → текст, `pdftotext -layout`,
1273 стор., 66 162 рядки). Повний текст лежить поруч у
`podatkovyy-kodeks-ukrayiny-povnyy-tekst.txt` (7 МБ, не .md — це сирий текстовий
першоджерельний файл, щоб не ламати форматування при відкритті).

> Кодекс величезний і покриває всі податки країни, з яких для нашої практики
> (консультування ветеранських ФОП, гранти, медична практика + роздрібна торгівля)
> реально релевантні лише кілька розділів. Рядок-в-рядок вичитані й законспектовані в
> `podatky-fop-2026.md` тільки вони. Решта збережена повністю про всяк випадок, але не
> вичитувалась детально — навігація нижче, щоб знайти потрібне швидко, якщо виникне
> конкретне питання (наприклад, ПДВ для клієнта, який стане платником ПДВ, або податок
> на прибуток, якщо клієнт зареєструє юрособу).
